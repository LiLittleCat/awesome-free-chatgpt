## ✨ Features

*   **Free to Use:** Access a wide range of ChatGPT mirror sites without any cost.
*   **Continuously Updated:** The list is regularly updated with new and verified links.
*   **Multiple Languages:** Available in both English and Chinese.
*   **Categorized Lists:** Easily find the type of service you're looking for, whether it's a direct mirror, an alternative, or a tool for developers.

---

## 🚀 How to Use

To get started, simply follow these steps:

1.  **Browse the Lists:** Go through the curated lists of ChatGPT mirrors and alternatives in the `README.md` and `README_en.md` files.
2.  **Select a Service:** Click on the link of the service that best suits your needs.
3.  **Start Chatting:** You will be redirected to the selected website where you can start interacting with the AI.

## 🛠️ Setup and Installation

To get the project running on your local machine, follow these steps:

1.  **Clone the Repository:**
    ```bash
    git clone https://github.com/LiLittleCat/awesome-free-chatgpt.git
    ```
2.  **Navigate to the Directory:**
    ```bash
    cd awesome-free-chatgpt
    ```
3.  **Run the Script (Optional):**
    The `convert.py` script is used to extract URLs from the `README.md` file and save them to `urls.json`.
    ```bash
    python convert.py
    ```
